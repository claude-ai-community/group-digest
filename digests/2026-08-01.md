### 模拟电路设计:AI 化最难啃的一块

D 分享:UCLA 模拟电路设计教授 Razavi(CMOS 模拟电路领域权威)测试 AI 在模拟电路设计中的表现——Gemini 得分约 60–70%,ChatGPT 仅 30–40%。Razavi 结论:模拟电路设计是艺术,AI 推导的等效电路有时不对,需要大量电路分析和提取简化;数字集成电路设计 AI 已能做很多,但大公司不会 100% 依赖 AI Agent 做设计(too risky),需要 human in the loop;模拟电路设计 even far away,大模型推导和解释对电路理解有些对有些不对,必须有经验专家检验。(D 还分享了 Razavi 的 analog design GitHub 仓库 razavi-bench 供参考,群里未附直接链接)

- Austin:模拟电路设计要做好要理解模拟电路的特性,这就是之前讲的"知识和智力"——要形成模拟电路设计的智力需要额外的工作,比如特别的 training
- MU:半年前,老程序员也是这么说的
- MU:最好不要搞,留一个瓶颈可以拿捏在 AI

Austin 还分享了与 Claude 讨论的截图,梳理出 EDA 中 AI 化的三大难点(数据稀缺且与工艺强绑定、抽象层次难以解耦、评估速度太慢难以应用 RL 或代理模型快速寻优),随后有人给出了更系统的六层拆解:

1. **数据几乎不存在**:数字电路有海量开源 RTL 可训练,模拟电路设计数据是各家公司命根子不外流,且数据和工艺强绑定——同一个运放换个 PDK,器件模型、尺寸、偏置全变;模拟设计的知识大量存在于工程师的直觉和手稿里,SPICE netlist 本身不携带设计意图
2. **没有可综合的抽象层次**:数字有 RTL → 门级 → 版图的清晰分层,可独立优化;模拟的增益、带宽、噪声、功耗、PSRR、失调之间强耦合,是个多目标帕累托问题,没法解耦成流水线
3. **评估太慢**:本质是"环境步进"代价过高——一次蒙特卡洛 + 全 corner 仿真可能几十分钟,而 RL 或贝叶斯优化动辄要上万次评估;代理模型(surrogate)能加速,但精度不够时优化会跑偏
4. **版图效应**:原理图仿真过了不代表能流片,寄生电容、器件匹配、走线电阻、热耦合、衬底噪声这个 schematic-to-layout gap 让 pre-layout 优化结果经常失真,把版图纳入优化循环又会让搜索空间爆炸
5. **目前只解决了"简单的那一半"**:学术界大部分成果是 given topology, do sizing,拓扑固定后优化器件尺寸,本质是参数搜索;真正有价值的拓扑创新,AI 目前基本没能力
6. **信任与可解释性**:一次流片几十万到几百万美元,设计师必须理解"为什么这么设计能 work",黑盒吐出的一组尺寸没法 debug,也没法在 review 会上辩护——这个障碍甚至比技术本身更难跨

一句话总结:模拟设计是**数据稀缺 + 评估昂贵 + 强物理约束 + 高失败代价**的四重叠加,恰好是当前深度学习范式最不擅长的组合。

### Leader.skill:把模糊需求转成 Agent 可执行的目标任务书

有作者开源了 Leader.skill,用于将模糊的人类需求转化为 Agent 可独立执行数小时的目标任务书。基于"目标七问"方法论,涵盖目的、完成态、反作弊、边界等维度,并推荐用 Claude Fable 5 或 Kimi K3 规划目标,再交由 GPT-5.6 Sol 或 GLM-5.2 等模型长程执行。(公众号"数字生命卡兹克"分享,[原文](https://mp.weixin.qq.com/s/AwOk3di8m6eVeIUjzNftgg))

### Agent 自组织,还是 Leader-Agent 层级?

Austin 读到一篇讲得通透的 Agent 文章([原文](https://mp.weixin.qq.com/s/lSbhHK0T5NUYuhwhgyK_LQ)),摘了一段引发自己思考的话:将来一个方向,是让 Agent 在工作中积累的经验能够保存、验证和传播;另一个方向,是让越来越多的 Agent 在稳定的规则下完成分工,并根据任务和能力调整自己的协作关系。

Austin 的延伸思考:分工应该按能力和正确性、或者按 credit 历史记录来进行。自组织的 agent 工作当然很好,但如果类比一个公司的组织结构,还是要有一个很 senior 的 lead——这个就是主程序,他有相应的经验或主见,由他去领导下面的 Agent 自组织,下面的 Agent 工作他可以选择或分配,依据是经验、以前的成功率和能力偏好;把工作划分分解到不同的 Agent,是不是在模仿人类工作情况,而不是完全的自组织,因为仍然需要有一个更有经验的领导 Agent。不过 Austin 也补充:关于"AI 组织",理想状态是更扁平的,而 Agent 本身能力越来越强,组织形态也会趋向扁平。(另见相关文章《给「AI 组织」交了好几波学费后,终于看清了这五级台阶》,[原文](https://mp.weixin.qq.com/s/MVBE8U_ikDZcoQFdeNvsmQ))
